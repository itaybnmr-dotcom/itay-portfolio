# CLAUDE.md

Implementation requirements for this portfolio site.

## Principles

- Black and white.
- Hovers come with a line that is drawn from one side to the other.
- The cursor is a circle.
- The fonts are always ABC Diatype and Reckless.

## What not to change

Everything.

## Phones

Follow the frames I design in Figma for the phone.

## Figma

Figma wins. If something in Figma is a mistake, I'll fix it.
As long as it isn't an effect that depends on CSS, Figma and my design win over everything.

## How we work

- Make the change I ask for.
- Show it on local and wait for my OK.
- Push only when I say so.

## Values

- No value is written directly in the code: everything goes through a variable in styles.css.
- If a variable is missing, ask me before adding one.

## The styleguide

styleguide.html is updated only when I ask.

## Language

English.
