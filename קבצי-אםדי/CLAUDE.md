# פורטפוליו אישי

אתר פורטפוליו אישי שנבנה מהעיצוב שלי בפיגמה.
קובץ הפיגמה: https://www.figma.com/design/Y2gG75Df5YijmuJF1Mtbek/Portfolio

## עיצוב
- פיגמה היא מקור ההחלטות.
- אל תמציא עיצוב. אם משהו חסר או לא ברור בפיגמה, שאל אותי.

## טכנולוגיה
- HTML, CSS ומעט JavaScript בלבד.
- בלי פריימוורקים ובלי כלי build.

## מבנה קבצים
- `index.html` ושאר העמודים נמצאים בתיקייה הראשית.
- גיליון סגנונות אחד: `styles.css`. הצבעים, הפונטים והריווחים מוגדרים כמשתני CSS בראש הקובץ.
- תמונות נמצאות בתיקייה `images/`.

## רספונסיביות
- כל עמוד צריך לעבוד בטלפון, בטאבלט ובמחשב.

## קוד קריא
- שמות ברורים והערות קצרות, כדי שמתחיל.ה יוכל.תוכל לקרוא את הקוד.

## עבודה איתי
- אחרי כל משימה, הסבר בעברית ב-2–3 משפטים פשוטים מה עשית.
- שאל אותי לפני שאתה מתקין משהו או מוחק קבצים.
